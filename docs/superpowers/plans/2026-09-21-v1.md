# Swipe Republic v1 implementation plan

Goal: deploy a complete, playable first release at swiperepublic.deadpackets.pw.
Spec: ../specs/2026-09-21-swipe-republic-design.md. User authorized autonomous implementation on 2026-09-21.

Architecture: React/Vite client, Worker API, SQLite Durable Object per society. Luna generates schema-validated worlds and cards; Jev evaluates faction reactions. Deterministic rules resolve decisions and succession. Use short batches if experiments show they preserve continuity with lower latency and cost.

Global constraints: both requested models; all credentials server-side; setting-specific factions and resources; mobile swipe plus accessible buttons; persistent promises and succession; bounded spend and retries; no speculative infrastructure or excessive tests.

- [x] 1. Prove integrations and choose visual direction. Files: scripts/experiment.ts, artifacts/design-study.html, package.json, wrangler.jsonc. Check: real Luna structured output, real Jev questions, recorded usage/latency, inspect three visual variants.
- [x] 2. Implement game contracts and deterministic engine. Files: src/game.ts, src/game.test.ts. Check: consequential decisions, due promises, victory, simultaneous defeat, successor inheritance, stale-card rejection, and finite campaign limits.
- [x] 3. Implement generation and persistence. Files: worker/ai.ts, worker/index.ts. Check: actual SDKs run in Workers, bounded schema validation/retries, idempotent turns, ownership, reservation expiry, daily quotas and budget reservation.
- [x] 4. Implement polished frontend. Files: src/App.tsx, src/style.css, src/Portrait.tsx, index.html. Check: setting interpretation, ambition, touch/buttons/keyboard previews, history, ending, succession, resume, and errors on mobile and desktop.
- [x] 5. Deploy and audit. Files: README.md, docs/verification.md. Check: build and focused tests, live game on the deployed Worker plus valid HTTPS on the custom domain, critical security checks, actual cost/latency, full v1 requirement audit.

Decisions: proceed with succession and archival paper. Use controlled visual alternatives to validate that direction. Local public test artifacts remain ignored. Documentation records any departures from the proposal and why.
